title: C ABI & UniFFI (Swift / Kotlin)
description: Cross-platform mobile bindings for iOS, macOS, and Android.

`ebook-rs` exports clean Mozilla UniFFI interfaces and standard C ABI functions:
- **Swift / iOS**: Generated CocoaPods / Swift Package Manager bindings.
- **Kotlin / Android**: High-speed JNI bindings with zero intermediate allocations.
- **C ABI**: Stable `ebook_rs.h` header for C/C++ integration.\n
