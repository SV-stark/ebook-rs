## ⚡ Format Conversion Benchmark

Empirically measured **v0.19.0 (`--release`, 3-run median)** conversion benchmarks vs Calibre 9.18 on *Alice in Wonderland* (Windows 11 / AMD Ryzen 9 / PCIe 4.0 NVMe):

| Conversion | 🚀 `ebook-rs` (v0.19.0) | 🐍 Calibre 9.18 | Speedup | Notes |
|---|:---:|:---:|:---:|---|
| **EPUB → KFX** | **0.31s** ⚡ | 60.99s *(KFX Output)* | **~195× Faster** | Clean-room Ion 1.0 `CONT` v2 |
| **EPUB → PDF** | **0.26s** ⚡ | 15.62s | **60.3× Faster** | Zero-dependency PDF 1.4 writer |
| **DOCX → EPUB** | **0.16s** ⚡ | 2.95s | **18.1× Faster** | 37 / 37 images preserved |
| **TXT → EPUB** | **0.11s** ⚡ | 1.98s | **17.8× Faster** | Auto-chapter & paragraph reflow |
| **CBZ → EPUB (21 MB)** | **0.83s** ⚡ | 12.87s | **15.5× Faster** | Natural-sorted comic spread archive |
| **TCR → EPUB** | **0.14s** ⚡ | 2.08s | **15.0× Faster** | Psion `!!8-Bit!!` dictionary codec |
| **AZW3 / PDB → EPUB** | **0.15s** ⚡ | 2.15s–2.19s | **14.7× Faster** | Native KF8 & PalmDOC/zTXT |
| **EPUB → TXTZ / RB** | **0.16s–0.23s** ⚡ | 1.92s–2.65s | **11.5–11.7× Faster** | Full Calibre CLI round-trip verified |

See the full 30+ format benchmark table in [Conversion Benchmarks](/ebook-rs/benchmarks/conversion/).

## 🛠️ Quick Installation

```toml
# Cargo.toml
[dependencies]
ebook-rs = "0.19.0"
```

```bash
# Python
pip install ebook-rs

# CLI Binary
cargo install ebook-rs
```
