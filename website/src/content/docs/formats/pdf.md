Powered by `pdf_oxide`, `ebook-rs` transforms fixed-page PDF documents into reflowable, responsive eBook chapters.

### Spatial Intelligence
- **2-Column Columnization**: Automatically detects multi-column scientific layouts and orders text reading order.
- **Heading Clustering**: Reconstructs document TOC hierarchy by analyzing font size distributions.
- **Header & Footer Stripping**: Eliminates page numbers and running headers for uninterrupted reading.\n
